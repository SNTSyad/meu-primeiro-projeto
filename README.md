# meu-primeiro-projeto
Aplicação simples de Tarot em HTML, CSS e JavaScript. Escolha o idioma e acompanhe um histórico das cartas sorteadas.

## Como executar

1. Instale o Python, caso não possua.
2. No diretório do projeto, execute `python3 -m http.server`.
3. Acesse `http://localhost:8000` no navegador.
4. Use o botão "Limpar Histórico" para apagar o registro e ocultar a carta exibida.
5. Alterar o idioma após sortear atualiza o texto da carta e o histórico.
